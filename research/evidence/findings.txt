Hogwarts Legacy name restrictions — installed Steam build 26175237

Conclusion
Name matching is local in the traced character-creation and Nurturing text-input Blueprints. There is also an asynchronous online list-update path. A nonempty online-manager list replaces the widget's list; otherwise an existing widget list is kept. If neither has entries, the widget loads the bundled DT_WizardWords table, selecting the current locale plus entries marked bAlwaysCheck. This is not a local-only design, but the traced RequestWizardWords path requests a list resource rather than sending each proposed name for validation.

Hash algorithm
For ordinary ASCII: lowercase hexadecimal MD5(UTF-8("phoenix" + lowercase(input))).
This is deterministic salted hashing, despite the native function being named EncryptString. It is not reversible encryption. Candidate plaintext is retained only when its exact salted digest matches an extracted row. Original capitalization cannot be recovered from lowercased hashes.
Native code additionally removes the UTF-16 sequence U+00E3 U+20AC U+20AC before UTF-8 conversion. Full Unicode lowercasing and edge-case behavior were not reproduced.

Matching behavior from complete shared Blueprint bytecode
ContainsBannedWord's CheckSubstrings=false mode checks the hash of the whole input only.
CheckSubstrings=true mode:
1. Empty input is not restricted by this matcher (separate UI checks enforce a name).
2. Hyphen-minus, ASCII apostrophe and backtick are replaced by spaces.
3. Space-delimited tokens of at most three characters are checked as whole tokens when multiple nonempty tokens exist.
4. Spaces are removed and every substring of length at least four is hashed and checked. If the resulting string has at most three characters, it is checked as a whole string instead.
Consequences: three-letter entries are not indiscriminately matched inside longer unbroken names; four-or-more-character entries can match inside otherwise ordinary names. Checks are not simply word-boundary matching.

Consumers
AvatarCreator.ValidatePlayerName checks the full FirstName + space + LastName in exact mode and checks each individual name in substring mode. Its final submission path enables profanity checking. The separate finalization-page validator has its own exact-mode calls; some edit-time calls disable profanity checking.
The Nurturing UI_BP_TextInputScreen checks its entered text in substring mode before accepting it. It has creature-name properties and is used for the traced beast naming UI. The same shared matcher and SetupWizardWords list-selection structure occur here.
The exact displayed English message is present in MAIN-enUS.bin under PlayerNamingError_Restricted: "The name you have entered contains restricted words."

Illustration, NOT an in-game runtime claim
An offline interpreter of the fully decoded matching bytecode, using modeled ASCII engine string/array builtins and the local English fallback, rejects Prometheus because the substring meth is in that table. The complete word prometheus itself is not a row. The same interpretation accepts Classic: ass is a three-letter row but does not match as an internal substring there. Results are saved in offline-bytecode-examples.json.

Limits
No game launch, injection, patch, save edit, or game-server request was performed. Public candidate dictionaries were read to recover hash preimages; those are not game-server calls. Native functions and Blueprint data were analyzed statically; offline bytecode interpretation is explicitly not observed game execution.
A running game may receive a different replacement list. The actual response body, endpoint/transport, current online availability and any unrelated telemetry are unobserved. Do not read these results as proof the game never transmits player names for any other purpose.
The remaining readable words cannot be recovered merely by decompressing the local asset: their source representation is one-way hash keys. More candidate recovery may be possible, but a complete original plaintext list has not been established.
No installed game files or repository source files were changed.
